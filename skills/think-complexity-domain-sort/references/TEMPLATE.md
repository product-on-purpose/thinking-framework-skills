# Complexity Domain Sort - Template

Fill this in. The deliverable is the domain placement plus its response posture and a concrete next action, not a bare label.

> **Evidence caveat (read first):** This sort is descriptively named; the framework it derives from is Cynefin, a trademark of The Cynefin Co. (Dave Snowden, 1999). Its evidence is tier C (conceptual): no controlled study shows that classifying a problem this way improves decisions, and the 2021 PMC internal-medicine review found "scientific proof of its validity has yet to be provided." The placement is a judgment, not a found fact. Saying "this is complex" is not a decision - the value below is the next action each domain implies. Invent no effectiveness statistic.
