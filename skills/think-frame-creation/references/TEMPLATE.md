# Frame Proposal - Template

Fill this in. The deliverable is the frame proposal - themes, core paradox and value, the IF/THEN "as if it were Y" frame, and the solution directions it unlocks - not a prose essay. Mark it explicitly as a standpoint to develop and test, never as a proven answer.

## Summary (top of the artifact)

[3-5 sentences. Name the value actually sought, the core paradox, and the new frame in one line ("approach it as if it were Y"). State the most important solution direction the frame unlocks. End by flagging that this is an untested standpoint to develop. A reader who stops here should know what the new frame is and that it is not yet proven.]

## Core paradox and value sought

- **Core paradox:** [the real conflict that makes the problem hard - the standpoints or requirements that cannot both be satisfied head-on. Used as the diagnostic that the current frame has failed, not as the thing to resolve directly.]
- **Value actually sought:** [what success would really deliver. This anchors the frame - the guard against reframing into a clever answer to the wrong question.]

## The new frame (abduced working principle)

- **Reconception:** approach the problem **as if it were [Y]** - [name the new kind of situation Y, earned by the themes above, that redefines what the problem *is*].
- **IF / THEN:** **IF** we see this situation as [Y] and adopt its working principle, **THEN** we create [the value actually sought].
- **What this changes:** [state plainly that the *problem* is now a different kind of problem - "this is not an [old frame] problem, it is a [Y] problem" - not just a different solution.]

> Check: is Y earned by the distilled themes (not free-associated)? Does it change the *problem*, not just suggest a solution? Could the people who own the problem actually adopt this standpoint? If any answer is no, the frame is not ready.
