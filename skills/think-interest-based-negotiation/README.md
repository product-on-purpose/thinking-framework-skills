# skills/think-interest-based-negotiation

`think-interest-based-negotiation` (Interest-Based Negotiation) is one of the `think-*` skills in `skills/` (67 in this plugin). It separates both sides' positions from their underlying interests, anchors the accept-or-walk decision on a named best alternative inside the mapped zone of possible agreement, and invents options for mutual gain before dividing value against objective criteria, producing a **negotiation preparation map**.
