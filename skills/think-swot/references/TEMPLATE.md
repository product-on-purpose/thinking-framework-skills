# Disciplined SWOT + TOWS - Template

Fill this in. The deliverable is the prioritized, evidence-tagged grid plus the TOWS option set, not a flat four-box list.

> **Evidence caveat (read first):** SWOT is tier X. Bare SWOT grids "did not constitute analysis" (Hill and Westbrook 1997). The value below is the discipline, not the boxes: tag each factor, prioritize to a few, and use the TOWS matching step to produce options. Do not report the grid as analysis, and do not invent effectiveness numbers.
