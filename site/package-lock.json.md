# package-lock.json

The npm lockfile for the docs site (`site/`), pinning the exact resolved version and integrity hash of every package in the dependency tree.

## What it does

It records the fully resolved tree behind the four direct dependencies in `site/package.json` (`@astrojs/starlight`, `astro`, `astro-mermaid`, `sharp`) plus all of their transitive packages, each with an exact version, registry URL, and integrity checksum. It is `lockfileVersion: 3` and names the root package `thinking-framework-skills-docs`.

## Why it matters

Committing the lockfile is what makes `npm ci` reproducible: CI installs the exact same versions that were resolved locally, so the Starlight build that emits the live site is deterministic. Without it, `npm install` could float to newer transitive versions and a build that passes locally could break in CI.

## Produced and consumed by

Generated by npm whenever the dependency set changes (`npm install`). It is consumed by `npm ci` during the docs build and by tooling that audits the dependency tree.

Do not hand-edit. To regenerate, change `site/package.json` and run `npm install` in `site/`, then commit the updated lockfile alongside it.
