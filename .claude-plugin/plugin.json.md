# plugin.json

The Claude Code plugin manifest for thinking-framework-skills. It is the file Claude Code reads to recognize, name, and install the plugin.

## What is in it

A small JSON object with the plugin's identity: `name` (`thinking-framework-skills`), `version`, a one-paragraph `description` of the library, `author`, `homepage` and `repository` URLs pointing at the GitHub repo, and a list of `keywords` for discovery. It does not contain the skills themselves; Claude Code auto-discovers those from the repo's skill directories at install time.

## Why it matters

This is the entry point. Without a valid manifest here, the marketplace install flow ("/plugin marketplace add product-on-purpose/agent-plugins" then "/plugin install thinking-framework-skills@product-on-purpose") has nothing to register, and the plugin will not load. The `name` here is what callers use to reference the plugin, and it must match the marketplace listing.

## Produced by / consumed by

Generated by the agent-skills-toolkit `gen-manifest` step from `library.json`, the library's source of truth. The `name`, `description`, `keywords`, and repo URLs are all derived from `library.json`. It is consumed by Claude Code at install and load time, and by the product-on-purpose marketplace listing.

## Do not hand-edit

Do not edit this file directly. Change the corresponding fields in `library.json` (at the repo root) and regenerate the manifest with `gen-manifest`. Hand edits will be overwritten on the next generation and will drift from the rest of the generated artifacts.
