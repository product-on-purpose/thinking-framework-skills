# docs/reference/

This folder holds the reference quadrant of the repo docs: pages you look things up in while working, not pages you read start to finish.

## Inventory

- [`authoring-contract.md`](./authoring-contract.md) - for each thing you author, where its rules live and which gate layer enforces them.

## Convention

A reference page here links to its source of truth rather than copying it, because the repo's [generated-view principle](../architecture.md#the-generated-view-principle-no-second-store) forbids a second store.
