# docs/how-to/

This folder holds the how-to quadrant of the Diataxis split used under [`../README.md`](../README.md): goal-oriented recipes for a reader who already has the basics and wants to accomplish one specific task. It is distinct from a from-scratch walkthrough (`docs/tutorials/`) and from an explanation of why things are shaped this way (`docs/explanation/`), its two sibling quadrants.

## Inventory

- [`run-the-conformance-gate-locally.md`](./run-the-conformance-gate-locally.md) - reproduces the CI conformance check on your own machine before opening a PR, for a contributor who has already read the contributing gate.
