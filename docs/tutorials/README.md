# docs/tutorials/

This folder holds the tutorials quadrant of the Diataxis split used under [`../README.md`](../README.md): hands-on, start-to-finish walkthroughs for learning by doing one concrete run. It is distinct from a goal-oriented recipe for a reader who already knows the basics (`docs/how-to/`) and from an explanation of why the system is shaped this way (`docs/explanation/`), its two sibling quadrants.

## Inventory

- [`run-a-recipe.md`](./run-a-recipe.md) - walks through chaining three skills with a recipe, carrying one compressed artifact between them, for a reader who has already run a single skill.
