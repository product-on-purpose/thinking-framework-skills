Held at M not S (normatively-contested direction, transfer failed, rule-indeterminacy); explicitly NOT downgraded M -> P because the controlled studies test THIS move with anchoring/probability/perspective-taking controls. Distinct on the principle axis + voiceless rows + non-aggregation wall. Admission note: swap the registry oneLine/reasoning to the entry.json text (live row is still the preliminary stub).
