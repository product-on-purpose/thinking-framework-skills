# .codex-plugin/plugin.json

The Codex-native plugin manifest that lets the OpenAI Codex CLI discover and load the thinking-framework-skills library.

## What is in it

A small JSON object with the plugin's identity and the pointer Codex needs to find the skills:

- `name`, `version`, `description`, `author`, `homepage`, `repository`, `keywords` - the same metadata the library carries elsewhere.
- `skills`: `"./skills/"` - the directory Codex scans to enumerate the 31 skills.
- `interface`: a `displayName` ("Thinking Framework Skills") and `category` ("Reasoning") for how Codex presents the plugin.

## Why it matters

Without this manifest, Codex has no entry point: it cannot find the skills directory or show the library in its plugin surface. This is the Codex-side counterpart to the Claude Code plugin manifest, so the same skills are installable across both agents (`npx skills add product-on-purpose/thinking-framework-skills`).

## Produced and consumed

Generated by the agent-skills-toolkit `gen-manifest` step from `library.json` (the single source of truth for library metadata). Consumed by the Codex CLI at discovery time.

Do not hand-edit. Change `../library.json` and regenerate the manifest so the two stay in sync. The skills themselves live in `../skills/`; see the authoring guide at `../docs/internal/AUTHORING.md`.
