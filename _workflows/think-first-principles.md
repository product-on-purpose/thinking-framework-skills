# Recipe: first-principles (workflow)

First-principles thinking is not a separate skill here: its durable moves are decomposition and assumption-stripping, both of which the library already ships. This recipe chains them honestly rather than dressing the pair up as a new method.

Run the steps in order, carrying forward only the compressed artifact between them:

1. `think-abstraction-laddering` -> carry the **irreducible level** (the fundamentals the problem reduces to).
2. `think-assumption-reversal` (on those fundamentals) -> carry **which baked-in assumptions are necessary vs inherited convention**.

Composite artifact: a fundamentals sheet - the irreducible truths that survive, the conventions stripped away, and a reconstruction built up from what is actually necessary. Full prose and rationale: `recipes/first-principles.md`.
