# Recipe: expand-options (workflow)

Run the steps in order, carrying forward only the compressed artifact between them:

1. `think-problem-restatement` -> carry the **chosen working frame**. (For blank-page breadth, swap in `think-brainwriting`.)
2. `think-scamper` -> carry the **SCAMPER shortlist**.
3. `think-assumption-reversal` -> carry the **combined shortlist** of candidates (flagged as candidates, not decisions).

Composite artifact: a de-duplicated shortlist of options spanning incremental variations and assumption-breaking alternatives, ready to hand to `think-decision-option-review`. Full prose: `recipes/expand-options.md`.
