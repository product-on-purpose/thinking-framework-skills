# templates

Scaffolding used to author a new thinking-framework skill in this plugin's own shape.

This folder is a top-level folder in the thinking-framework-skills plugin, a sibling of `skills/`. Its content is copied, not executed: a new skill starts from `templates/skill/` and the placeholder `think-REPLACE-method` naming is filled in by hand.

## Inventory

- `skill/` - a seed skill (`SKILL.md`, `evidence/dossier.md`, `references/EXAMPLE.md` and `references/TEMPLATE.md`, `skill.meta.yml`) to copy into `skills/think-<method>/` and fill in for a new framework.
